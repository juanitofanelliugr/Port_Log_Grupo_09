# Port Log - Grupo 09

## Sprint 2

### Objetivo
Continuar el análisis del Puerto Fluvial de Rosario a partir de los datos
procesados durante el Sprint 1, incorporando nuevas fuentes y herramientas
de análisis.

### Introducción y contexto
En este sprint se continuará trabajando sobre los resultados obtenidos en
el Sprint 1. Se utilizará el dataset procesado previamente y se incorporará
un conjunto de imágenes relacionadas con los movimientos portuarios para
ampliar el análisis del proyecto.
