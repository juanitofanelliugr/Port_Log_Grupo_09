# Port Log - Grupo 09

## Sprint 1

### Objetivo
Realizar la limpieza, procesamiento y análisis de los datos históricos
del Puerto Fluvial de Rosario.

### Introducción y contexto
En este sprint se trabajará con los registros históricos del puerto,
realizando tareas de diagnóstico, limpieza, procesamiento y análisis
de los datos para obtener información confiable y útil.
