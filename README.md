# Port Log - Grupo 09

## Sprint 1

### Objetivo
Realizar la limpieza, procesamiento y análisis de los datos históricos
del Puerto Fluvial de Rosario.

### Introducción y contexto
En este sprint se trabajará con los registros históricos del puerto,
realizando tareas de diagnóstico, limpieza, procesamiento y análisis
de los datos para obtener información confiable y útil.

## Sprint 2: Procesamiento de imágenes

En este sprint se trabaja con un conjunto de 100 imágenes
relacionadas con los movimientos portuarios.

Las actividades incluyen:
- Preparación y organización de las imágenes.
- Extracción de información y metadatos.
- Procesamiento de imágenes mediante OpenCV.
- Vinculación de las imágenes con los registros portuarios.
- Análisis de resultados y elaboración de conclusiones.

Los datos utilizados se encuentran en las carpetas
`port_log/data/raw/` y `port_log/data/interim/`.
